description: React/Next.js 컴포넌트를 Vercel best practices 기준으로 리뷰합니다
---

현재 파일 또는 $ARGUMENTS 경로의 컴포넌트를 읽고 다음 기준으로 리뷰해줘.

**확인 항목**

1. **Server/Client 분리**
   - 불필요한 `'use client'` 사용 여부
   - 서버에서 처리 가능한 로직이 클라이언트에 있는지

2. **성능**
   - 불필요한 리렌더 발생 여부
   - `useCallback` / `useMemo` 누락
   - 이미지에 `next/image` 미사용
   - 링크에 `next/link` 미사용
   - 큰 라이브러리 번들 포함 여부

3. **데이터 페칭**
   - 폭포수(waterfall) fetch 패턴 여부
   - 캐시 전략 적절성
   - 로딩/에러 상태 처리 여부

4. **타입 안정성**
   - any 타입 사용 여부
   - props 타입 누락
   - 불필요한 타입 단언(as)

5. **접근성**
   - alt 텍스트 누락
   - 시맨틱 HTML 미사용
   - 키보드 접근 불가 요소

6. **코드 품질**
   - 컴포넌트 크기 (너무 크면 분리 제안)
   - 중복 코드
   - 하드코딩된 값

각 항목별로 문제점과 개선 코드를 같이 보여줘.
